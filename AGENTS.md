# Instruções para agentes (Codex, Claude)

**Documento novo** (proposta, plano, apresentação em PDF para órgão público): use o molde.
- Leia `moldes/README.md`.
- Copie `moldes/exemplos/sispac-ro/`.
- Escreva só o `conteudo.yaml`.
- Gere com `python3 moldes/gerar.py <pasta>/conteudo.yaml`.

Não escreva HTML ou CSS de documento. Se faltar um bloco, ele entra no molde para todos os documentos.

**Painel e abas do site:** veja o `README.md`. A fonte de cada número está em `FONTES.md`.

**Regras de conteúdo:**
- Todo número sai de `dados-fonte/` ou de fonte pública com data.
- Se o número depende de uma regra de contagem, a regra vai escrita no rodapé.

Não faça commit sem pedido.
